# Boss 清单

依据当前 `data/war3map.j` 的怪物注册及 `data/table/unit.ini` 的单位名称统计。单位 ID 区分大小写，名称已去除颜色码。

## 统计口径

- 明确配置 Boss 档位 `gP=1～5`：37 个主单位 ID，档位沿用脚本数值。
- 其它 `O9pO` 特殊注册单位：6 个，包含活动单位“特大号灯笼”，单列核对，不全部认定为常规 Boss。
- 野外首领补充：6 个 `O90O` 注册单位；巨魔领主在教学文本中明确称为 Boss，其余作为野外首领候选。
- 不将 `O99O` 关联的分身、召唤物、阶段单位另算一个 Boss，不包含英雄时装、背包和坐骑外观。

## 脚本定位说明

- `O9pO` 注册单位基础信息，并配置 `tP`、`TP` 两组行为数据。
- `gP[ZP]` 是分档字段，脚本据此调整复活次数及部分挑战功能。
- `Iiuq` 建立 Boss 管理对象及挑战交互，并非全部 Boss 的统一注册入口。
- 本表为静态注册清单，不表示每局、每个活动期间都会实际生成。
