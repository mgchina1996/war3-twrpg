# Boss 顶部血条

实现位于 `data/war3map.j` 的 `TwrpgBossBar*` 函数，使用官方对战平台 DzFrame。本文记录当前代码行为。

## 显示与目标切换

每位玩家独立保存一个 Boss 目标，每 0.05 秒刷新自己的血条，注册范围为 49 个主单位 ID。

获取或切换目标时，玩家主英雄必须存在、存活、自定义生命值大于零，且不处于墓碑或灵魂等待复活阶段。目标必须是已注册、存活的敌方 Boss；实际显示还要求该 Boss 对玩家可见。

| 触发情况 | 当前行为 |
| --- | --- |
| 玩家单位对 Boss 下达目标指令 | 将该 Boss 设为目标 |
| 玩家单位普通攻击 Boss | 将被攻击的 Boss 设为目标 |
| Boss 普通攻击玩家单位 | 为该单位所属玩家设置 Boss 目标 |
| 单纯选中或取消选中 Boss | 不改变目标，不触发显示或隐藏 |
| 英雄死亡、进入墓碑或灵魂阶段 | 保留原目标；禁止获取或切换新目标 |
| 技能复活后重新交战 | 恢复正常获取和切换目标 |

当前目标指令和普通攻击事件并不要求伤害已经命中。事件按单位所属玩家处理，也包括该玩家的召唤物；多个 Boss 触发时，最后一次有效触发覆盖原目标。

## 隐藏与目标清除

“隐藏”只影响 UI；“清除目标”会结束追踪，之后需要重新触发才能显示。

| 情况 | 血条 | 是否清除目标 |
| --- | --- | --- |
| 没有目标 | 隐藏 | 已无目标 |
| Boss 暂时不可见 | 暂时隐藏，可见后恢复 | 否 |
| Boss 死亡或被移除 | 隐藏 | 当前代码保留引用 |
| 英雄死亡、墓碑或灵魂等待 | Boss 可见且存活时继续显示 | 否 |
| 默认回复活点成功 | 立即隐藏 | 是 |
| 技能指定位置复活 | 继续按原 Boss 状态显示 | 否 |
| 主英雄被移除或玩家主英雄索引清空 | 隐藏 | 是 |

当前没有距离脱战、无伤害超时、Boss 重置检测或死亡后零血停留逻辑。Boss 死亡不会主动清除引用；如果同一单位被复活且重新可见，原目标可能再次显示。

## 复活来源判断

在 `Op90` 调用 `ReviveHero` 后，确认复活成功，再根据复活类型 `y4` 处理：

- `y4=0`：墓碑等待后的默认回点复活，清除目标并隐藏。
- `y4=1`：灵魂流程的默认回点复活，清除目标并隐藏。
- `y4=2`：技能指定位置复活，保留目标。

判断依据是复活流程类型，不是复活坐标。死亡事件和进入墓碑流程不再清除目标。目标清除在所有客户端同步执行，立即隐藏只操作对应玩家的本地 UI。

## 外观与数值

无头像、无整块背景板。Boss 名称统一为红色，居中位于血槽上方；血槽采用深紫底色和纯红色填充，白色分界线随血量移动，绿色数值固定在完整血槽中央。

数值格式为 `剩余血量  -  剩余血量百分比`，例如 `199747  -  33.0%`。生命值显示为整数，百分比保留一位小数，不显示括号和 `/100%`。

地图管理的单位使用 `uq1O`、`uqiO` 读取自定义生命值；其它单位回退到原生生命值。填充比例限制在 0～100%，空血时隐藏填充；满血时隐藏分界线。

## 布局与资源

在 `TwrpgBossBarInit` 中调整位置和尺寸：

- 左上角：`.238, .55`，使用 DzFrame 的 0.8 × 0.6 屏幕坐标。
- 整体尺寸：`.324 × .032`。
- 有效血槽：`.32 × .014`，宽度由 `TWRPG_BOSS_BAR_WIDTH` 控制。
- 字号：`.009`；名称下边缘锚定血槽上边缘中央，间隔 `.004`。

打包时应用 `data/resources/manifest.json`，导入以下资源：

| 内部路径 | 用途 |
| --- | --- |
| `UI\TwrpgBossBar\Border.tga` | 边框 |
| `UI\TwrpgBossBar\Track.tga` | 深紫底槽 |
| `UI\TwrpgBossBar\Fill.tga` | 纯红色填充，无 WARNING 纹理 |
| `UI\TwrpgBossBar\Edge.tga` | 白色分界线 |
