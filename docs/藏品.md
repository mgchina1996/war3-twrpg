`OO6O` 用于**给指定玩家发放藏品奖励，并防止重复领取**。

```jass
function OO6O takes player p,integer ollo returns nothing
```

- `p`：领取奖励的玩家。
- `ollo`：藏品 ID，例如 `'shdt'`。

执行流程：

1. 检查该 ID 是否已注册到藏品系统，未注册直接返回。
2. 调用 `OOoO` 检查玩家是否已拥有，已有则直接返回。
3. 调用 `OOIO`，将藏品加入玩家的藏品系统。
4. 显示“藏品名称获得奖励.”通知，并播放提示音。

例如：

```jass
// 给玩家解锁火焰梦魇力量结晶，已拥有则跳过
call OO6O(Player(0),'shdt')
```

它发放的是**藏品系统里的拥有记录**，不会直接在地上创建物品或放进英雄背包。

`l6opi` 用于**仅在玩家使用指定英雄时，发放指定藏品奖励**。

```jass
function l6opi takes integer oIIO,integer O6oO,integer ollo returns nothing
    if cz[ql[oIIO]]==O6oO then
        call OO6O(P[oIIO],ollo)
    endif
endfunction
```

参数含义：

- `oIIO`：玩家索引。
- `O6oO`：要求的英雄 ID。
- `ollo`：要发放的藏品 ID。

例如：

```jass
call l6opi(oIIO,'H008','I0HF')
```

表示：玩家英雄为 **灵魂炽女（H008）** 时，发放 **万圣节服装 2（I0HF）**；其他英雄跳过。

内部通过 `OO6O` 发奖，因此已拥有该藏品时不会重复发放。
