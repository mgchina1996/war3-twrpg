# 英雄可用时装

来源：`data/war3map.j` 的 `iq6p` 时装列表与 `i90p` 英雄外观映射；名称来自 `data/table/item.ini` 和 `data/table/unit.ini`。

`i90p(时装类型, 原英雄ID, 换装后单位ID, 图标)` 注册可用关系；`i91p` 按原英雄 ID 查找当前选中时装的外观。下表表示脚本支持的搭配，实际使用仍需拥有并选中对应时装。不同英雄 ID 分开列出，避免混淆职业或阶段。

## 时装列表

```jass
// I0FT 海洋服装
call iq6p(1,'I0FT')
// I0GC 夏装
call iq6p(1,'I0GC')
// I0GF 周年庆气氛
call iq6p(1,'I0GF')
// I0GI 激情四射
call iq6p(1,'I0GI')
// I0ID 休闲服装
call iq6p(1,'I0ID')
// I0H3 万圣节服装
call iq6p(1,'I0H3')
// I0HF 万圣节服装 2
call iq6p(1,'I0HF')
// I0H4 圣诞节服装
call iq6p(1,'I0H4')
// I0H5 新年服装
call iq6p(1,'I0H5')
// I0HE 新年服装 2
call iq6p(1,'I0HE')
// I0HC 轮回之花
call iq6p(1,'I0HC')
// I0L6 特殊服装
call iq6p(1,'I0L6')
// I0OY 世界大咖·欧皇服装
call iq6p(2,'I0OY')
```

本表排除奇装异服（`I0HM`）和疯狂的奇装异服（`I0IC`）。保留 13 个时装 ID，其中 12 个配置了英雄外观映射。`I0HC`（轮回之花）仅注册到服装分类，当前脚本未见 `i90p` 英雄映射，因此不列入英雄可用表。
